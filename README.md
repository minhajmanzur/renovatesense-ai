# RenovateSense AI

RenovateSense AI turns a short renovation walkthrough into a visual triage brief and a draft, dependency-ordered repair scope. It is a local-first prototype for architects, contractors, and property teams who need a structured starting point before an on-site inspection.

## What it does today

- Accepts MP4, MOV, M4V, AVI, MKV, and WEBM walkthroughs up to 100 MB and three minutes.
- Uses OpenCV to sample up to eight evenly spaced frames.
- Sends sampled frames to a configured Gemini or OpenAI vision model and validates the returned findings and repair sequence.
- Shows findings alongside the reviewed keyframes, limitations, and a suggested scope of work.
- Calculates illustrative labor, material, and schedule bands using a small starter rate card displayed in AED.

## How it works

```text
Walkthrough video → OpenCV keyframes → Gemini or OpenAI vision review
                  → structured findings → draft repair sequence and planning bands
```

The backend is FastAPI. The browser interface is plain HTML, CSS, and JavaScript served by the API. Configure exactly one provider or leave `AI_PROVIDER=auto` to prefer Gemini when its key exists, then fall back to OpenAI.

## Run locally

Requirements: Python 3.10 or newer and an API key for Gemini or OpenAI.

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

Edit `.env` and set one provider key:

```dotenv
AI_PROVIDER=gemini
GEMINI_API_KEY=your_key_here
```

For OpenAI instead, set `AI_PROVIDER=openai`, add `OPENAI_API_KEY`, and optionally set `OPENAI_VISION_MODEL`. Never commit `.env` or share an API key. The `.env` file is excluded by `.gitignore`.

Start the app:

```powershell
uvicorn backend.main:app --reload
```

Open <http://127.0.0.1:8000>. The health endpoint is <http://127.0.0.1:8000/api/health>.

## Configuration

| Variable | Purpose | Default |
| --- | --- | --- |
| `AI_PROVIDER` | `auto`, `gemini`, or `openai` | `auto` |
| `GEMINI_API_KEY` | Gemini API key | unset |
| `GEMINI_VISION_MODEL` | Gemini vision model | `gemini-3.5-flash-lite` |
| `OPENAI_API_KEY` | OpenAI API key | unset |
| `OPENAI_VISION_MODEL` | OpenAI vision model | `gpt-4o-mini` |
| `MAX_UPLOAD_MB` | Maximum video size | `100` |
| `MAX_INSPECTION_FRAMES` | Maximum sampled keyframes | `8` |

## Important limitations

This is a visual planning prototype, not an inspection or diagnostic system. The model can miss defects or produce false positives. Video frames cannot establish structural safety, concealed damage, mold species, or electrical compliance. Hire qualified professionals for site assessment, and treat all cost and duration bands as illustrative until calibrated with local contractor data.

This release does **not** include a trained YOLO/Mask R-CNN detector, LangGraph orchestration, or an XGBoost estimator. Findings are generated by the selected vision model. The sampled frames are sent to that provider for review; check the provider's terms before using sensitive property footage.
